# Развёртывание контент-завода

Ты разворачиваешь этот репозиторий на машине пользователя до состояния «работает на автомате».
Веди по шагам, после каждого показывай результат проверки. Секреты пользователь вписывает
СВОЕЙ рукой — ты их не читаешь и не печатаешь.

## Шаг 1 — окружение

Проверь и покажи пользователю:

```bat
python --version     &REM нужен 3.10+
claude --version     &REM Claude Code CLI — двигатель AI-этапа
pip show flask       &REM для пульта; нет -> pip install flask
```

Нет Claude CLI → поставить по официальной инструкции (claude.com/claude-code) и войти в аккаунт.

## Шаг 2 — секреты (рука пользователя)

1. `copy .env.example .env`
2. Попроси пользователя открыть `.env` в блокноте и вписать:
   - `TELEGRAM_BOT_TOKEN` — токен бота (@BotFather), бот должен быть **админом канала**;
   - `TELEGRAM_CHANNEL` — свой канал;
   - `OPENAI_API_KEY` — только если нужны картинки (без него завод собирает черновики без картинок).
3. Сам файл НЕ открывай. Проверь только факт существования: `if exist .env echo ok`.

## Шаг 3 — тест рельсов (без AI и без ключей)

```bat
set CF_DRAFT_MODE=stub
python content_factory_run.py
```

Проверка: появился `_STATUS.md` с вердиктом «готово» и файл-заявка `_DRAFT_REQUEST_*.txt`
в `drafts/`. Нет — разбери ошибку до перехода дальше.

## Шаг 4 — боевой прогон одного черновика

```bat
run_scheduled.bat
```

Идёт ~10 минут: субагент ищет повестку, проверяет факты, кладёт JSON + ПРЕДПРОСМОТР в `drafts/`.
Проверка: в `drafts/` появился новый `.json`, в `_STATUS.md` — «готово» с его именем.

## Шаг 5 — пульт апрува (человек-гейт)

```bat
run_console.bat
```

Открой пользователю <http://127.0.0.1:5055>: он видит черновик и решает — «Одобрить и
опубликовать» (уйдёт в канал, черновик переедет в `published/`) или «Отклонить» (в `rejected/`).
Напомни: публикация происходит ТОЛЬКО по его клику — так и задумано, это не баг.

## Шаг 6 — автоматика

```bat
schtasks /Create /TN PDN_ContentFactory_Draft /SC DAILY /ST 09:00 /TR "<абсолютный_путь>\run_scheduled.bat"
```

Проверка: `schtasks /Query /TN PDN_ContentFactory_Draft /V /FO LIST` — задача есть, время верное.
Покажи пользователю, как посмотреть итог утреннего прогона: файл `_STATUS.md` в корне.

## Аварийный тормоз

Создать файл `STOP` в корне — плановые прогоны выходят, ничего не делая. Убрать файл — завод снова жив.

## Чего НЕ делать

- Не публиковать в канал самому и не «тестировать» публикатор без явной просьбы пользователя.
- Не вписывать и не читать значения ключей; не коммитить `.env` (он в .gitignore).
- Не менять редполитику (`docs/EDITORIAL_POLICY.md`) — это правила канала, их меняет владелец.
