## 9. ПРИЁМКА MVP (обкатка локально)
Готово, когда Каэл-управляющий по команде:
1. делает **срез** → дедуплицированный шортлист тем со источниками;
2. на выбранную тему — **проверенный** текст (сверка с первоисточником) + картинку;
3. кладёт **читаемое превью**, ждёт апрув;
4. по «публикуй» — постит в @pdn152fz_check, возвращает message_id;
5. пишет тему в **дедуп-леджер** (следующий срез не повторяет).
Один сквозной цикл с двумя человек-гейтами = приёмка.
